## 다음 단계 agent가 알아야 할 핵심 5줄
1. 2026년 KOSPI 매도 세금 = 증권거래세 0.05% + 농어촌특별세 0.15% = **0.20%**. 매수 시 세금 없음. PLAN.md의 "세금 0.15%"는 **틀렸다**(0.20%로 갱신 권고).
2. KIS 온라인(HTS/MTS) 수수료는 **0.0140527%**(유관기관 수수료 포함). PLAN.md의 0.015%는 반올림 값으로 **사실상 맞다**(보수적 가정으로 허용).
3. 백테스트 권고 비용: 매수 0.015%, 매도 0.015% + 0.20% = **0.215%**. 왕복 약 0.23%.
4. 2026-06-01 ~ 09-30 평일 휴장일은 **5일**: 06-03(지방선거), 07-17(제헌절), 08-17(광복절 대체공휴일), 09-24·09-25(추석). 추석 대체공휴일은 없다. 백테스트 구간(08-31 ~ 09-29) 내 휴장은 09-24, 09-25뿐.
5. 호가 단위는 가격대별 1/5/10/50/100/500/1,000원(2023-01-25 개편). 매매는 1주 단위. 시가·종가는 이미 호가 단위에 맞는 실제 체결가라 백테스트에서 호가 보정은 불필요하다.

| 주가 구간 | 호가 단위 |
|---|---|
| 2,000원 미만 | 1원 |
| 2,000원 ~ 5,000원 미만 | 5원 |
| 5,000원 ~ 20,000원 미만 | 10원 |
| 20,000원 ~ 50,000원 미만 | 50원 |
| 50,000원 ~ 200,000원 미만 | 100원 |
| 200,000원 ~ 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

- 원 출처의 세부 구간(5천~1만, 1만~2만 모두 10원 등)을 합쳐 정리했다. ETF·ETN은 별도이며 유니버스에 없다.
- 백테스트 영향: 시가·종가는 실제 체결가라 호가 보정 불필요. 수량 = floor(배분금액 / (시가 × (1 + 매수수수료율))). 슬리피지는 0(PLAN 기본값).
